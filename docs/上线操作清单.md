> 全程在手机/电脑浏览器登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) 操作，开发者工具不用再开。

## 1. 提审前必办的 5 件事（按顺序做，第 1 件最慢，先启动）

### ① 小程序备案（唯一会拖时间的，1～20 个工作日）

- 路径：后台左侧 **设置 → 小程序备案 → 去备案**
- 材料：主体证件（个人身份证 / 企业营业执照）、小程序负责人证件、人脸核身、承诺书
- 规矩：**没备案就不能发布**，点发布会直接报 `86369 小程序上架需先完成备案`
- 建议：**今天就去提交**，审核期间代码该改什么改什么，两件事并行

### ② 服务类目（不改会被判"类目与内容不符"）

- 路径：**设置 → 基本设置 → 服务类目 → 添加类目**
- 本项目选：
  - 主类目：**工具 → 健康管理**（个人主体免资质，适用范围就是"身高、体重等健康管理记录"）
  - 可加选：**体育 → 在线健身**
- ❌ 不要选医疗、问诊、医药相关类目 —— 需要《医疗机构执业许可证》，你拿不到

### ③ 基本信息（审核员第一眼看到的就是这些）

- 路径：**设置 → 基本设置**
- 名称：大理论时代
- 头像：`docs/小程序头像/icon-144.png`（144×144 PNG，已生成好）
- 简介：一句话讲清干什么，例如
  > 记录喝水、饮食、睡眠、训练四件小事，用像素小人陪你把健康习惯坚持下去。数据默认只存本机。
- 服务内容声明：勾选「健康管理」相关项，**不要勾**涉及医疗诊断、药品的内容

### ④ 用户隐私保护指引（健康数据类小程序的重点检查项）

- 路径：**设置 → 服务内容声明 → 用户隐私保护指引 → 更新**
- 必须声明收集的信息（你这个小程序全都有）：
  - 身高、体重、年龄、性别 → 用于计算饮水/热量目标
  - 饮水、饮食、睡眠、训练记录 → 用于打卡统计与积分
  - 若开了榜单：昵称、头像、分数 → 用于排行榜展示
- 用途统一写「用于本小程序内的健康数据记录与统计；不对外提供、不用于广告」
- 存储说明：「记录默认保存在用户手机本地；开启排行榜后分数存储于微信云开发」
- 删除方式：「我的 → 数据与备份 → 清空数据；卸载小程序即全部删除」

> 微信审核对"收集了健康信息但没说"非常敏感，这一项写漏基本必被驳回。

### ⑤ 微信认证（后台提示了再做）

- 个人主体约 30 元/次、企业主体 300 元/次，有效期一年
- 未认证会影响搜索曝光、部分能力，**是否卡提审以后台提示为准**
- 后台没提示就先跳过，别多花钱

## 2. 云开发：不开也能提审，但建议开（30 分钟）

现状：`miniprogram/config.js` 里 `cloudEnvId` 还是空的 → 排行榜页显示"本地单机"降级提示。

审核员如果点到榜单页看到"暂不可用"，有可能判「功能不完整」。两条路：

**A. 图省事**：不开云开发。提审时在备注里写清"排行榜为可选功能，需登录微信并开通云开发后使用"——有概率过，也有概率被打回。

**B. 建议**：开通，一次性做完：
1. 开发者工具左上角 → **云开发** → 开通 → 复制环境 ID
2. 填进 `miniprogram/config.js` 的 `cloudEnvId`
3. 云开发控制台 → 数据库 → 新建 4 个集合（权限都选「仅管理端可读写」）：
   `dt_scores`、`dt_users`、`dt_buddies`、`dt_invites`
4. 建索引（不建会重复加分）：`dt_scores` 的 `_openid + date + module` 唯一索引、
   `dt_users` 的 `_openid` 唯一索引、`dt_buddies` 的 `_openid + buddyOpenid` 唯一索引
5. 右键 `cloudfunctions` 下 4 个云函数 → **上传并部署（云端安装依赖）**
6. 回开发者工具重新「上传」一次代码

> 详细到每一步的版本见 `docs/云端搭建步骤.md`

**好消息**：本小程序不用买服务器、不用配 request 合法域名。全部本地 + 云开发，省掉域名备案那一整套。

## 3. 提交审核

1. 后台 **管理 → 版本管理 → 开发版本**，找到你刚传的版本
2. 点 **提交审核**
3. 按提示填写：
   - **功能页面路径**：`pages/home/index`
   - 类目：与第 ② 步一致
   - 标签：健康、习惯打卡、减脂
   - 测试账号：本项目无需登录，留空
   - 补充说明（很重要，写清楚能少挨一轮）：
     > 本小程序为个人健康习惯记录工具，不提供医疗诊断。数据默认仅存本机。排行榜需微信登录并开通云开发，未开通时自动降级提示。无付费、无广告、无诱导分享。
4. 提交后：**审核一般 1～7 天**，管理员微信会收到结果通知
5. 审核期间**别急着改代码重传**，会把审核版本覆盖掉

---

## 4. 发布

审核通过 → 后台 **版本管理 → 审核版本 → 发布**：

- **全量发布**：所有人立刻用新版（首次发布选这个）
- **分阶段发布**：按比例灰度，功能多、用户多时再用

发布后：
- 后台 **设置 → 基本设置** 补齐搜索关键词，用户才能搜到
- **工具 → 生成小程序码**，可下载印刷/发朋友圈
- 「我的 → 关于」里的版本号记得跟 `config.js` 的 `version` 对上

## 5. 最可能被驳回的 5 个点（提前改掉，省一轮 7 天）

| 风险 | 位置 | 审核为什么拦 | 改法 |
|---|---|---|---|
| ⚠️ **"抗炎理论"** | `utils/constants.js` 第 62 行、anti 页标题 | "抗炎"是医学功效表述，健康管理类目无资质不得宣称 | 改名「抗氧打卡」「饮食多样打卡」，或保留但在页首加灰字免责声明 |
| ⚠️ **无隐私政策入口** | 全项目 0 处 | 收集身高体重却没给查看隐私条款的地方，健康类高频驳回 | 「我的 → 关于」里加一条进入隐私政策页 |
| ⚠️ **"弱者喝饮料，强者喝大水"** | `config.js` waterSlogan | 带贬损/绝对化倾向，可能被判不当表述 | 改「少喝甜的，多喝大的」 |
| 排行榜不可用 | rank 页 | 判"功能不完整/白屏" | 见第 2 节，开云开发或备注说明 |
| 诱导分享 | rank 页分享 | 若有"分享得积分"必拒 | 当前只分享邀请码、不加分，✅ 安全 |

前三条我都可以直接改代码，改完你重传一次即可（上传会覆盖开发版本，不额外花钱）。

## 6. 时间表

```
今天：提交备案（1～20 工作日）＋ 补类目、基本信息、隐私指引
  ↓
备案审核中：开云开发、改掉第 5 节的风险点、重新上传代码
  ↓
备案通过 + 后台配置齐：提交审核（1～7 天）
  ↓
审核通过：发布（全量）→ 下载小程序码 → 开始推广
```

顺利的话 **2～4 周**能上线；只卡在备案排队的话，代码这边其实一两天就能全部弄完。

## 零、先看这个：可点击试用原型

不想装开发者工具，或想先让人试用，直接打开根目录的 **`大理论时代-试用预览.html`**。

- 它是一个网页版的完整交互原型：开屏 → 引导 → 今日 → 大水 / 抗炎 / 大睡 / 薄肌 → 趋势 → 榜单 → 我的，全部可以点。
- 记录是真的会存：喝水、勾抗炎、填睡眠、加训练都会写进浏览器本地存储，积分实时累加，刷新不丢。
- 左侧面板有「填入 14 天演示数据」和「清空并回到开屏」两个按钮，方便快速看趋势图和非空状态。
- 目标公式、判定线、积分规则与小程序**同一套**：热量 2520、饮水按体重 × 32.5ml（68kg → 2.2 升）、抗炎 3 类合格、四项各 10 分。
- 榜单在原型里用的是模拟好友（浏览器不可能读到微信好友），真机版走云开发。

> 它只是预览用的网页，不参与小程序打包；`小程序界面预览.html` 是三屏静态图，已被这个交互版取代。

## 一、怎么跑起来（5 步）

1. **导入项目**：微信开发者工具 →「导入项目」→ 选择本目录（含 `project.config.json` 的那一层）。
2. **换 AppID**：`project.config.json` 里 `appid` 现在是 `touristappid`（游客模式，不能开云开发）。换成你自己的小程序 AppID。
3. **编译**：直接点「编译」。首屏会出现木框 + 举哑铃的小人，1.2 秒后进引导（第一次）或首页。
4. **（可选，要看榜单才需要）开云开发**：
   - 开发者工具左上角「云开发」→ 开通 → 记下环境 ID；
   - 把环境 ID 填进 `miniprogram/config.js` 的 `cloudEnvId`；
   - 右键 `cloudfunctions` 下四个目录 →「上传并部署（云端安装依赖）」；
   - 云数据库建 4 个集合：`dt_users`、`dt_scores`、`dt_buddies`、`dt_invites`；
   - **给 `dt_scores` 手动建唯一索引**：字段 `_openid`(升序) + `date`(升序) + `module`(升序)，勾选「唯一」。少了这一步，双击会发两次分。
5. **真机预览**：点「预览」扫码。像素小人与图表在真机上才看得出真实效果。

> 没配云开发也能完整使用：记录、积分、趋势、备份全部照常，只有「榜单」页会显示「还没接上云端」，榜单上只有你自己。
